Inspectez les requêtes comme dans les outils de développement

Network Inspector reçoit le trafic capturé par l’extension navigateur (fetch, XHR) via WebSocket et l’affiche dans un panneau type DevTools : liste, waterfall, détails (en-têtes, aperçu JSON, réponse), comparaison et export / import de session.

Aperçu

Objectif

Centraliser la capture réseau hors onglet pour analyser méthodes, statuts, durées et corps de réponse sans quitter votre flux de travail.

Fonctionnalités

  • Flux en direct des requêtes réseau capturées
  • Graphique waterfall et filtres sur la liste
  • Détail : en-têtes, aperçu, réponse, comparaison de deux requêtes
  • Export / import JSON ou HAR, thème clair / sombre

Comment utiliser

  1. Téléchargez le ZIP de l’extension, décompressez-le : un dossier dist apparaît. Dans Chrome (ou Chromium), ouvrez Extensions → Mode développeur → Charger l’extension non empaquetée et sélectionnez ce dossier dist.
  2. Assurez-vous que le serveur WebSocket attendu par l’extension est démarré pour que le trafic remonte vers cette application.
  3. Ouvrez l’inspecteur dans le navigateur avec le bouton ci-dessous : les requêtes apparaissent dans le panneau Network ; sélectionnez une ligne pour afficher le détail à droite.
